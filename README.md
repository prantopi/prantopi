### What I'm building

**[Claudemon](https://github.com/prantopi/claudemon)**: a small floating window that shows what every Claude Code session and subagent is doing right now: current action, tokens, speed, model mix and usage limits. It reads Claude Code's local logs, so nothing leaves your machine. Native Swift on macOS, Python on Windows and Linux.

<p align="center">
  <a href="https://github.com/prantopi/claudemon"><img src="https://raw.githubusercontent.com/prantopi/claudemon/main/docs/demo.gif" width="560" alt="Claudemon showing live Claude Code sessions, agents and token usage"></a>
</p>

**[Claude Code Dev Team](https://github.com/prantopi/claude-code-dev-team)**: one setup script that turns Claude Code into a nine-agent software team. Agents gather requirements, design, plan, build, test, review and document. Coding agents run in parallel in separate git worktrees, and nothing counts as done until the reviewer agent approves it. Each agent runs on a model priced for its job.
